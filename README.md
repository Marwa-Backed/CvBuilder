# CvBuilder

CV Builder - ASP.NET app to create and download professional CVs.

Build a professional CV in minutes. Add your personal info, education, experience, skills, and download it as a clean, ready-to-send CV.

## Features

- Create and edit your CV easily
- Live preview while you type
- Professional templates
- Download CV as PDF
- Clean and responsive design

## Tech Stack

- ASP.NET Core
- C#
- HTML / CSS / JavaScript
- Visual Studio
